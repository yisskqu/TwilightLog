回滚步骤（已验证数据侧，代码侧为标准流程）：

1. 应用：重新部署上一版本镜像；或 `git revert <阶段 7 squash commit>` 后重新构建。迁移 00005 为新增字段/索引，旧二进制可直接运行。
2. 数据：`pg_restore` 最近备份到新库，修改 `DATABASE_URL` 后重启 API；媒体卷从归档恢复。
3. 验证：`/readyz` 200 → 管理员登录 → `/api/v1/admin/reviews` 可读 → 公开文章/相册可访问 → 抽样图片 200。

## 8. 发现的问题与修复

| # | 问题 | 级别 | 处理 |
|---|---|---|---|
| 1 | `workspace.Service.owner` 自递归，提交/移入回收站触发栈溢出并导致 API 容器重启 | P0 | 改为调用 `repo.Owner`，重新构建镜像验证 |
| 2 | 非法 UUID 路径参数直达数据库，审批/详情返回 500 | P1 | 新增 `workspace.IsUUID` 与 `uuidParam`，统一返回 404；父级/媒体 ID 非法时返回 400 |
| 3 | React StrictMode 下并发调用刷新接口，refresh token 轮换竞争导致登录态被清空 | P0 | `refreshSession` 改为单飞（single-flight），并发请求共享同一个 Promise |
| 4 | 公开站 dev 服务在 `NODE_ENV=production` 环境下启动，React island 报 `jsxDEV is not a function`，查看器无法交互 | 环境 | 以开发环境变量重启 dev 服务；E2E 增加 island 水合等待 |
| 5 | `.eyebrow` 文字对比度 4.38:1，未达 WCAG AA | P1 | 主色由 `#b45309` 调整为 `#a94e07`（4.9:1） |
| 6 | 管理后台输入框/按钮缺少可见焦点样式 | P1 | 增加全局 `:focus-visible` 规则 |
| 7 | sitemap 包含已 noindex 的 `/search` | P2 | Astro sitemap 增加 `filter` 排除 `/search` |
| 8 | `golang.org/x/image v0.24.0` 存在 2 个可达漏洞（SFNT/TIFF 内存耗尽） | P1 | 升级到 v0.39.0，`govulncheck` 归零 |

已确认不是缺陷的行为：管理员回收站默认只显示自己拥有的条目，需勾选「查看全站」查看他人内容（与阶段 6 设计一致）。

## 9. 遗留事项

1. **依赖公告（部署前处理）**：`pnpm audit --prod` 报告 Astro 5.18.2、sharp、zod、esbuild 的构建期公告（1 critical / 6 high）。项目未使用 `astro:assets`/远程图片优化，运行时不加载 sharp；但仍建议在阶段 8 前升级 Astro 7.x 并复跑本套用例。
2. **SEO 301**：本地栈没有公开站反向代理，`/path` 与 `/path/` 均直接返回 200；生产需在阶段 8 的 Caddy 中配置尾斜杠与域名归一化的 301，并补充验收。
3. **E2E 未进入 CI**：整套用例需要完整 compose 栈、种子数据与三个前端服务，当前在本地执行；阶段 8 将增加 E2E workflow（compose up + seed + playwright），本轮已把 PostgreSQL 加入 Go 测试 job。
