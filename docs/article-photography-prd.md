## 1. 背景与目标

网站同时承载文章和摄影作品：

- **文章**：主要参考旅记和程序开发技术文档的阅读风格，支持图片、代码块、超链接、公式、Mermaid 和长文目录。旅记与技术文档只用于设计参考，不作为内容分类或筛选标准。
- **摄影作品**：主要题材为街拍、自然风光和城市风光，通过“摄影专栏—相册—照片”组织内容，兼容不同画幅。
- **内容生产**：编辑上传和管理自己的内容，所有新增及修改必须经管理员审批后才能公开；管理员拥有完整管理和审批权限。
- **文件安全**：原图私有保留，公开端只提供压缩且剥离元数据的衍生图片，不提供原图下载。

### 1.1 产品目标

1. **访客能发现内容**：通过搜索、多标签组合、日期筛选、排序和分页找到文章或摄影作品。
2. **访客能舒适消费内容**：文章完整呈现多种内容块；照片以瀑布流和大图弹窗展示。
3. **编辑能安全维护本人内容**：只能管理自己创建或上传的内容，并能跟踪审核结果、修改和重新提交。
4. **管理员能控制公开质量**：审批所有编辑新增及修改，管理全站内容、账号权限、首页推荐和回收站。
5. **公开内容稳定**：编辑修改在审核期间不覆盖已公开旧版；驳回不清空公开内容。
6. **浏览体验连续且个性化**：适配 PC、平板和手机，记住用户主动选择的浅色或深色主题。

### 1.2 产品契约

| 角色 | 触发 | 核心任务 | 完成条件 |
|---|---|---|---|
| 访客 | 打开公开页面，或登录但没有编辑权限 | 浏览、搜索、阅读文章或查看摄影作品 | 只看到已审批且公开可见的内容，不看到编辑身份和后台信息 |
| 编辑 | 获得管理员授权并登录 | 创建、上传、修改、下线本人内容并提交审核 | 本人内容进入审核；通过后公开，驳回后能看到原因并继续修改 |
| 管理员 | 使用由云服务器添加的管理员账号登录 | 审批内容、管理所有内容和账号、配置首页及系统、永久删除文件 | 全站公开内容、权限和文件状态符合管理操作结果 |

### 1.3 信任边界

- 公开端只展示当前已审批公开版本，不展示草稿、待审核版本、驳回版本、回收站内容或编辑身份。
- 编辑之间不能查看或修改彼此的非公开内容，也不能修改对方已公开内容。
- 访客无论通过页面保存、直接请求图片还是其他公开访问方式，都只能获得无嵌入元数据的压缩衍生图。
- 发布、审批、撤权、下线和永久删除均需要明确权限、影响范围和操作结果。
- 审批或上传失败不得让未审核内容意外公开，也不得重复创建已成功的内容。

## 2. 首版范围与核心流程

### 2.1 P0 范围

| 模块 | 首版能力 |
|---|---|
| 全局首页与导航 | 网站介绍、文章与摄影入口、可配置数量的首页推荐、登录入口、主题切换 |
| 文章公开端 | 文章专栏列表 → 专栏内文章列表 → 文章详情与目录 |
| 摄影公开端 | 摄影专栏列表 → 专栏内相册列表 → 照片瀑布流 → 照片详情弹窗 |
| 五类公开列表 | 搜索、多标签“全部包含”筛选、日期筛选、排序、每页 12 项 |
| 登录分权 | 访客、编辑、管理员；管理员创建账号并授予编辑；管理员账号仅通过云服务器添加 |
| 编辑工作区 | 本人专栏、文章、相册、照片管理；草稿、提交审核、撤回、下线、恢复和审核记录 |
| 管理员后台 | 全内容管理、审批中心、账号权限、首页推荐、回收站和系统管理 |
| 上传与图片安全 | 格式和大小校验、单次最多 20 张、分片上传、原图私有、压缩衍生图、剥离元数据 |
| 回收站 | 软删除、恢复、管理员二次永久删除并清除文件 |
| 多端与主题 | PC、平板、手机公开浏览；不同比例照片瀑布流；主题偏好本地保存 |

### 2.2 首版边界

- 公开端不提供评论、点赞、收藏或订阅。
- 首版不提供编辑之间协作编辑、内容所有权转让或多人共同拥有同一内容。
- 首版不提供管理员在后台自行创建其他管理员；管理员账号只能由云服务器添加。
- 不在本文决定具体框架、数据库、存储服务、鉴权框架或部署技术。

### 2.3 访客核心流程

```text
进入首页
  ├─ 文章
  │   文章专栏列表
  │   → 搜索 / 多标签、日期筛选 / 排序 / 分页
  │   → 专栏内文章列表
  │   → 文章详情 / 富文本 / 目录定位
  │
  └─ 摄影
      摄影专栏列表
      → 搜索 / 题材、多标签、日期筛选 / 排序 / 分页
      → 专栏内相册列表
      → 相册照片瀑布流
      → 照片大图、描述、元数据、可选位置
```

### 2.4 编辑内容流程

```text
管理员授予编辑权限
  → 编辑登录
  → 创建本人专栏 / 相册 / 文章 / 照片
  → 保存草稿
  → 提交管理员审核
  ├─ 审核通过 → 形成公开版本 → 公开端可见
  └─ 审核驳回 → 查看理由 → 修改 → 重新提交

修改已公开内容：
创建工作版本
  → 提交审核
  ├─ 审核期间：公开端继续显示旧版
  ├─ 审核通过：新版替换旧版
  └─ 审核驳回：公开端继续显示旧版，编辑修改工作版本
```

### 2.5 管理员核心流程

```text
管理员登录
  ├─ 审批中心 → 查看提交版本和差异 → 通过 / 驳回
  ├─ 内容管理 → 新增 / 编辑 / 发布 / 下线 / 移入回收站
  ├─ 账号管理 → 创建账号 / 授予或撤销编辑权限 / 重置密码 / 禁用启用
  ├─ 首页推荐 → 配置目标数量 / 选择并排序 / 查看补位结果
  └─ 回收站 → 恢复 / 二次确认永久删除并清除文件
```

## 3. 账号、角色与内容归属

### 3.1 角色定义

| 角色 | 定义 |
|---|---|
| 访客 | 未登录用户，以及已登录但没有编辑权限的用户；两者公开浏览能力一致 |
| 编辑 | 由管理员授予编辑权限的登录用户，只能管理自己创建或上传的内容 |
| 管理员 | 由云服务器添加的账号，拥有编辑能力、全站内容管理、审批、账号权限、首页配置和系统管理权限 |

### 3.2 权限矩阵

| 能力 | 访客 | 编辑 | 管理员 |
|---|---:|---:|---:|
| 浏览公开内容 | 是 | 是 | 是 |
| 切换并保存主题 | 是 | 是 | 是 |
| 登录 / 退出 | 可选 | 是 | 是 |
| 查看非公开内容 | 否 | 仅本人内容 | 全部 |
| 创建专栏、文章、相册、照片 | 否 | 仅本人内容树 | 是 |
| 修改内容 | 否 | 仅本人创建或上传的内容 | 全部 |
| 直接发布或使修改上线 | 否 | 否，必须审批 | 是 |
| 撤回本人待审版本 | 否 | 是 | 可处理全部待审版本 |
| 审批编辑内容 | 否 | 否 | 是 |
| 下线内容 | 否 | 本人内容 | 全部 |
| 移入回收站 / 恢复 | 否 | 本人内容 | 全部 |
| 永久删除及清除文件 | 否 | 否 | 是 |
| 创建账号 / 授予或撤销编辑权限 / 重置密码 / 禁用启用 | 否 | 否 | 是 |
| 添加管理员 | 否 | 否 | 否，仅云服务器操作 |
| 设置首页推荐与目标数量 | 否 | 否 | 是 |
| 查看内容所有者和审核记录 | 否 | 仅本人内容 | 全部 |

### 3.3 登录与会话 `FR-AUTH`

1. 未登录用户可以浏览公开内容，不被强制跳转登录。
2. 已登录但没有编辑权限的用户仍按访客处理，不显示编辑工作区。
3. 编辑和管理员登录后进入与其权限匹配的工作区。
4. 所有内容修改、审批、推荐配置和永久删除操作都校验当前身份与权限，不能只依赖隐藏按钮。
5. 用户可主动退出；退出后回到访客状态，不公开其账号信息。
6. 会话失效后，新的管理操作被拒绝并引导重新登录；已保存内容保持不变。
7. 重新登录后，根据当前最新权限决定能否继续原操作，不沿用过期权限。
8. 所有普通账号由管理员在后台“账号权限”页创建，不开放自助注册；创建时设置用户名、邮箱和初始密码，用户使用用户名登录。
9. 支持“记住登录”；不提供验证码、密码找回和自行修改密码；忘记密码由管理员在账号权限页重置。
10. 允许同一账号在多个设备同时登录。
11. 管理员可禁用或启用账号；禁用后不能登录，已登录会话在下次管理操作时被拒绝。禁用账号不等同于撤销编辑权限。
12. 账号字段：用户名（唯一，用于登录）、邮箱（唯一，用于后台搜索和账号识别；首版不发送邮件）、角色、状态（启用 / 禁用）、创建时间。管理员账号仍只能由云服务器创建，后台不提供其创建、删除、重置密码或禁用入口。

### 3.4 管理员授权与撤权 `FR-ADMIN-USERS`

**创建账号与授予编辑权限：**

- 管理员可在账号权限页创建普通账号，填写用户名、邮箱和初始密码；创建后账号默认是访客。
- 管理员可对已有账号授予编辑权限，也可在创建账号时一并授予，两步合并为一次操作。
- 授权后，该账号获得本人内容工作区，但此前不自动拥有任何他人内容。
- 管理员可重置普通账号密码、禁用或启用普通账号；禁用不影响已公开内容的归属，只阻止登录。
- 管理员账号的新增不经过公开注册或后台账号页，只能由云服务器完成。

**撤销编辑权限：**

1. 撤销后，该账号按访客处理，不能继续提交、修改或下线内容。
2. 已打开的编辑页面不能继续执行新的管理操作，并提示权限已变化。
3. 撤权不自动下线该编辑此前已获批的公开内容，这些内容的所有者转为管理员。
4. 待审核内容由管理员接管，原编辑不能再修改或撤回；管理员可继续审批、驳回或下线。
5. 撤权后原编辑不再拥有任何内容，也不可见其原内容的后台记录。

### 3.5 内容归属 `RULE-OWNERSHIP`

1. 每篇内容和每个容器均记录所有者，所有者信息只在授权后台使用，公开端不展示编辑名称、头像或其他身份信息。
2. 编辑只能查看和管理自己创建或上传的专栏、文章、相册、照片及其工作版本。
3. 编辑只能在自己拥有的文章专栏下创建文章，在自己拥有的摄影专栏下创建相册，在自己拥有的相册下上传照片。
4. 编辑不能向他人专栏或相册添加内容，不能修改、下线、恢复或移入回收站他人内容。
5. 管理员可以管理全部内容；管理员代编辑操作时不改变原内容所有者。
6. 编辑后台中的数量、列表和审核记录只统计本人可见内容，避免通过计数推断他人非公开内容。
7. 首版不支持共同编辑和编辑之间的所有权转让；撤销编辑权限时归属权转给管理员是唯一例外。

### 3.6 直接地址访问与越权防护 `RULE-ROUTE-GUARD`

前端隐藏入口只是界面便利，不是权限控制。后台页面、编辑地址、审批地址、内容详情地址和文件地址都必须在服务端校验身份、角色和内容归属。

| 访问场景 | 处理结果 |
|---|---|
| 未登录访问编辑工作区或后台地址 | 跳转登录页；登录成功后仅当有权限才回到原地址 |
| 访客（含已登录但无编辑权限）访问 `/editor` 或 `/admin/*` | 显示统一的“无权访问”页面，不展示后台框架、菜单和任何内容数据 |
| 编辑访问管理员页面（审批、账号、系统管理、永久删除等） | 按无权访问处理 |
| 编辑访问他人内容的编辑地址 | 显示统一的“内容不存在或无权访问”，不区分“存在但无权”，不返回标题、所有者等字段 |
| 访客访问已下线、待审核或回收站内容的详情地址 | 按不存在处理，不展示标题、摘要或封面 |
| 访客访问原图或带元数据文件地址 | 拒绝，只允许公开压缩衍生图，见 `RULE-MEDIA` |
| 管理员被撤销权限或禁用后停留在后台页面 | 下一次请求即被拒绝，提示权限变化并退出到登录页 |

**参数与枚举防护：**

1. 地址或请求参数中的所有者、角色、审核状态等字段不能扩大可见范围；服务端以当前登录身份覆盖客户端传入值。
2. 不允许通过修改 `id`、页码或筛选参数访问他人内容或非公开内容；越权与不存在的响应保持一致。
3. 预览链接只对已登录且有权限的用户生效，不生成无需登录即可访问的非公开内容预览地址。
4. 错误页面不返回内容标题、所有者、审核状态、文件地址等可用于推断的信息。
5. 后台页面不能“先加载数据再隐藏”；无权限时不应产生内容数据请求。
6. 设备分级 `RULE-ADMIN-DEVICE` 只约束界面入口，不能替代上述服务端校验。

## 4. 内容对象、版本与状态

### 4.1 内容对象

| 对象 | 核心字段 | 说明 |
|---|---|---|
| 文章专栏 | 所有者、名称、简介、封面、主题标签、创建时间、更新时间、公开状态 | 不设置“旅记 / 技术文档”筛选字段 |
| 文章 | 所有者、标题、所属文章专栏、摘要、多个本作用域主题标签、发布时间、更新时间、正文内容块、公开状态 | 公开端不展示所有者 |
| 摄影专栏 | 所有者、名称、简介、封面、摄影题材、多个本作用域主题标签、创建时间、更新时间、公开状态 | 题材用于摄影专栏筛选 |
| 相册 | 所有者、所属摄影专栏、标题、简介、封面、多个本作用域主题标签、创建时间、相册最新更新时间、主要拍摄位置、公开状态 | 相册最新更新时间由公开照片的上传时间产生 |
| 照片 | 所有者、所属相册、原图、公开衍生图、标题、描述、多个本作用域主题标签、上传时间、拍摄时间、可展示元数据、可选结构化位置、公开状态 | 支持任意宽高比例 |
| 首页推荐 | 推荐类型、目标内容、管理员顺序、目标展示数量 | 推荐文章与推荐相册分别配置 |
| 标签词库 | 标签名称、作用域（文章 / 摄影）、状态、使用数量 | 两个作用域独立维护，允许同名但互不通用 |
| 审核记录 | 提交人、提交版本、审核人、审核时间、决定、驳回理由 | 编辑仅看本人记录，管理员看全部 |
| 账号权限记录 | 账号、角色变化、操作管理员、时间 | 管理员账号的服务器添加不在本站后台完成 |

### 4.2 公开版本与工作版本

同一内容可以同时存在：

- **公开版本**：最近一次编辑审批通过或管理员直接发布，且当前允许公开的版本。
- **工作版本**：编辑或管理员正在修改的版本，可以是草稿、待审核或已驳回版本。

```text
新内容：
无公开版本 + 工作版本待审核 → 公开端不可见
审核通过                     → 工作版本成为首个公开版本
审核驳回                     → 仍无公开版本，编辑继续修改

修改已公开内容：
旧公开版本 + 新工作版本待审核 → 公开端继续显示旧版
新工作版本审核通过           → 新版替换旧版并公开
新工作版本审核驳回           → 旧版继续公开，工作版本保留驳回理由
```

**版本规则：**

1. 编辑每次新增或修改都必须形成待审核工作版本，不直接改变公开版本；文章专栏、摄影专栏、文章、相册、照片都遵循同一规则，编辑提交后公开端仍显示原公开版本，只有管理员审批通过后才更新。
2. 审核期间编辑不能静默改写已提交版本；需要修改时先撤回，再编辑并重新提交。
3. 管理员审核看到的是明确提交版本，审批结果对应同一版本，避免审核期间内容变化。
4. 管理员直接修改内容时，可保存并立即更新公开版本；系统记录操作时间和操作管理员。
5. 待审核、撤回或驳回不影响已有公开版本。
6. 只有审批通过的修改才更新公开端对应内容的更新时间。
7. 公开版本被下线后仍可重新提交上线；编辑重新上线也需要审批。

### 4.3 公开状态与审核状态

**公开状态：**

| 状态 | 含义 | 公开端表现 |
|---|---|---|
| 草稿 | 尚未形成公开版本 | 不展示 |
| 已发布 | 存在获批公开版本 | 上级也公开时展示 |
| 已下线 | 曾有公开版本，但当前主动隐藏 | 不展示 |
| 回收站 | 被软删除，文件暂时保留 | 不展示 |

**审核状态：**

| 状态 | 含义 | 后续操作 |
|---|---|---|
| 无待审版本 | 当前没有等待管理员处理的工作版本 | 可新建修改并提交 |
| 待审核 | 工作版本已提交且锁定 | 编辑可查看或撤回；管理员可通过或驳回 |
| 已驳回 | 最近一次提交未通过 | 编辑查看理由、修改并重新提交 |

> 公开状态与审核状态独立。例如，一篇文章可以同时是“已发布 + 待审核”，表示旧版公开、新版等待审批。

### 4.4 公开可见条件 `RULE-VISIBILITY`

内容只有同时满足以下条件才出现在公开端：

1. 公开状态为“已发布”。
2. 当前公开版本已由管理员审批通过，或由管理员直接发布。
3. 所有上级均为公开可见状态。
4. 不在回收站。
5. 涉及图片的公开衍生版本已生成且可用于公开展示；无图片内容不受此条件限制。
6. 相册至少包含一张公开照片；没有公开照片的相册不在公开端展示。

**上级变化规则：**

- 上级下线或进入回收站后，下级全部暂时隐藏，但下级自身公开状态不自动改变。
- 上级恢复公开后，符合其他条件的下级可恢复展示。
- 上级不可见时，管理员不能审批通过下级为公开可见状态；可选择驳回或等待上级恢复。
- 首页推荐只选择实际公开可见内容，失效推荐自动移除并补位。

### 4.5 时间字段

| 字段 | 产生与修改规则 | 用途 |
|---|---|---|
| 创建时间 | 首次创建专栏或相册时生成，不可由公开端修改 | 专栏日期筛选、后台管理 |
| 发布时间 | 文章提交发布时填写，不得晚于提交当天 | 文章筛选与排序 |
| 照片上传时间 | 全部上传分片完成并形成有效原图时生成，不等于拍摄时间或审批时间 | 计算相册最新更新时间 |
| 拍摄时间 | 从可用照片信息读取，上传者可补充或修正；发布前必填 | 照片筛选与排序 |
| 相册最新更新时间 | 由当前公开照片的上传完成时间计算，待审照片不参与；照片不再公开时回算 | 相册日期筛选、默认排序和首页补位 |
| 文章更新时间 | 最近一次文章新增或修改获批公开的时间；管理员直接公开修改时同步更新 | 默认排序和首页补位 |
| 专栏更新时间 | 由专栏下当前公开内容派生的只读时间：文章专栏取旗下公开文章更新时间的最大值，摄影专栏取旗下公开相册最新更新时间的最大值；没有公开内容时取专栏创建时间。仅修改专栏名称、简介、封面或标签不改变该时间 | 专栏默认排序与卡片展示 |

**相册时间特别规则：**

- 编辑上传照片后，待审核期间不改变公开相册最新更新时间。
- 管理员审批通过照片时，以该照片的**上传完成时间**参与计算，而不是使用审批时间；只有该时间晚于相册当前最新更新时间时才更新，避免较早上传、较晚审批的照片覆盖较新的时间。
- 管理员直接上传并公开照片时使用同一计算规则。
- 替换照片图像视为一次新的上传，获批公开后参与相册时间计算。
- 仅修改相册标题、简介、封面、标签、位置或照片文字信息，不改变相册最新更新时间。
- 照片被下线、移入回收站或永久删除时，相册最新更新时间回算为当前剩余公开照片中最晚的上传完成时间。
- 照片恢复公开时重新参与比较，再次成为最新时间则更新相册最新更新时间。
- 相册没有任何公开照片时，不在公开端展示；对访客和无编辑权限的用户均不可见。

## 5. 公开浏览端功能需求

### 5.1 全局导航与首页 `FR-HOME`

**页面布局：**

1. 顶部：网站标识、“首页 / 文章 / 摄影”导航、登录或账号入口、浅色 / 深色切换。
2. 首屏：网站介绍和文章、摄影主入口。
3. 推荐文章区：数量由管理员配置。
4. 推荐相册区：数量由管理员配置。
5. 深层页面：面包屑和返回上一级入口。
6. 公开页面不展示内容所属编辑、审核状态或后台备注。

**首页推荐规则：**

- 推荐文章目标数量为 `N₁`，推荐相册目标数量为 `N₂`，由管理员分别配置。
- `N = 0` 时隐藏对应推荐区，但保留文章或摄影主入口。
- 首页先展示管理员设置且当前公开可见的内容，严格按管理员顺序排列。
- 有效手动推荐不足 `N` 时，从其他公开可见内容中按更新时间从新到旧补足。
- 文章按文章更新时间补位，相册按相册最新更新时间补位。
- 自动补位不得与手动已选项重复。
- 管理员未设置任何推荐时，完全自动按更新时间补位。
- 公开内容不足 `N` 时展示实际数量；没有公开内容时隐藏对应推荐区。
- 推荐项被下线、进入回收站或因上级变化而不可见时，不占据首页位置，立即补位。
- 修改推荐顺序或目标数量不改变内容自身更新时间。

**入场动效：** 推荐卡片进入视口时淡入上移，具体参数与限制见 10.4 `RULE-MOTION`；动效不改变推荐排序、补位结果和加载顺序。

```text
某推荐区最终内容
= 管理员已选且公开可见的内容（按管理员顺序）
+ 未入选的其他公开内容（按对应更新时间新到旧、去重）
→ 取前 N 项
```

### 5.2 文章专属页：文章专栏列表 `FR-ACOL`

**专栏卡片：**封面、名称、简介、主题标签、文章数（仅统计当前公开可见文章）、创建日期和最近更新时间。

**查询规则：**

- 搜索：专栏名称与简介。
- 标签筛选：可多选，按 `RULE-TAG` 的全部包含规则执行。
- 日期筛选：按专栏创建日期。
- 排序：最近更新（默认）/ 文章数从多到少。
- 分页：每页 12 项。

**结果：**点击专栏进入该专栏文章列表；空专栏显示“暂无文章”。

### 5.3 文章专栏页：文章列表 `FR-ALIST`

**布局：**面包屑、专栏名称与简介、文章总数、查询工具栏、文章卡片和分页。

**文章卡片：**标题、摘要、多个标签、发布时间和最近更新时间，不展示编辑身份。

**查询规则：**

- 查询只作用于当前专栏。
- 搜索：文章标题与摘要。
- 标签筛选：多选且全部包含。
- 日期筛选：按文章发布日期。
- 排序：最新发布（默认）/ 最早发布。
- 分页：每页 12 项。

**结果：**点击文章进入详情；返回时恢复全部查询状态和页码。

### 5.4 文章详情 `FR-ADETAIL`

**布局：**面包屑、标题、所属专栏、发布时间、更新时间、标签、正文和目录。

**目录规则：**

1. 根据二、三级标题生成，点击后定位并高亮当前章节。
2. 手动滚动时同步目录状态，目标标题不被导航遮挡。
3. PC 端正文与目录并列；窄屏使用正文上方的可滚动目录。
4. 没有可用标题时隐藏目录。
5. 正文结束后保留至少一屏“阅读余量”，确保最后一个标题也能滚动到视口顶部；余量区块承载“本文完、上一篇 / 下一篇、返回顶部”，不做纯空白。
6. 文章较短、全部标题本身已可到达视口顶部时，不强制撑出一屏空白。

**内容块规则：**

| 内容块 | 展示要求 | 异常处理 |
|---|---|---|
| 文字与标题 | 保留段落、层级、列表和强调样式 | 无 |
| 图片 | 使用无元数据衍生图，保持比例，支持替代文本和图注 | 显示失败说明和重试，不影响正文 |
| 代码块 | 保留缩进与换行，左上角显示语言标签，右上角提供一键复制，长行内部滚动 | 复制失败给出提示，不改变原文；不撑破页面 |
| 超链接 | 链接可辨识，外部链接带标识并在新标签页打开 | 后台提交时校验链接格式 |
| 公式 | 支持行内和独立公式，过长时内部滚动 | 显示原始公式、失败说明和重试 |
| Mermaid | 按可用宽度展示，过密图示可横向查看 | 显示原始文本、失败说明和重试 |

**代码块交互：**

1. 每个代码块使用“头部条 + 代码区”结构，语言标签固定在左上角，复制按钮固定在右上角；头部条不随代码横向滚动移动。
2. 点击复制后复制完整原始代码，不包含语言标签、行号、提示文字或多余缩进。
3. 复制成功后按钮短暂显示“已复制”并恢复；复制失败显示“复制失败”，通过 `aria-live` 告知读屏，原文不受影响。
4. 非安全上下文或旧浏览器下使用隐藏文本框兜底，保证本地打开页面时仍可复制。
5. 语言标签取代码围栏的语言标识，常见别名映射为可读名称（如 `js` → JavaScript、`ts` → TypeScript、`py` → Python、`sh` → Shell），无法识别时显示“代码”。
6. 复制按钮在桌面端默认低对比常显、悬停或聚焦时增强；触屏设备常显，不依赖悬停。
7. 复制按钮与语言标签不参与代码选中，避免用户框选时被一起选中。

### 5.5 摄影专属页：摄影专栏列表 `FR-PCOL`

**专栏卡片：**封面、名称、简介、摄影题材、主题标签、相册数（仅统计当前公开可见相册）、创建日期和最近更新时间。

**查询规则：**

- 搜索：专栏名称与简介。
- 题材筛选：全部 / 街拍 / 自然风光 / 城市风光。
- 标签筛选：多选且全部包含。
- 日期筛选：按专栏创建日期。
- 排序：最近更新（默认）/ 相册数从多到少。
- 分页：每页 12 项。

### 5.6 摄影专栏页：相册列表 `FR-PCOLIST`

**相册卡片：**封面、标题、简介、主题标签、创建日期、相册最新更新时间、可选主要拍摄位置和照片数。

**查询规则：**

- 查询只作用于当前摄影专栏。
- 搜索：相册标题、简介和主要拍摄位置。
- 标签筛选：多选且全部包含。
- 日期筛选：按相册最新更新时间的日期。
- 排序：最新更新（默认）/ 照片数从多到少。
- 分页：每页 12 项。

**空状态：**相册没有任何公开照片时不在公开端展示；编辑和管理员仍可在后台查看并继续上传或提交照片。

### 5.7 相册详情与照片瀑布流 `FR-ALBUM`

**布局：**面包屑、相册标题与简介、创建时间、相册最新更新时间、可选位置、照片数、查询工具栏、瀑布流和分页。

**瀑布流规则：**

1. 按可用宽度分栏，不强制统一卡片高度。
2. 保持照片原始宽高比，不裁切、拉伸或压扁。
3. 横版、竖版、16:9、4:3、1:1 及其他比例可混排。
4. 图片加载前按照片尺寸预留位置，减少布局跳动。
5. 瀑布流不改变查询结果顺序和每页 12 项的分页规则。
6. 键盘访问顺序与内容排序一致。
7. 单张衍生图加载失败只影响该照片位置，可单独重试。

**查询规则：**

- 搜索：照片标题、描述和可选位置。
- 标签筛选：多选且全部包含。
- 日期筛选：按照片拍摄日期。
- 排序：拍摄时间从新到旧（默认）/ 从旧到新。
- 分页：每页 12 项。

### 5.8 照片详情弹窗 `FR-PHOTO`

**大图：**完整容纳于可用区域并保持比例；PC 优先大图与信息区并列，窄屏上下排列；横竖照片均不裁切。

**大图查看区：**

1. 弹窗内的图片查看区使用固定尺寸，不随照片比例和上一张/下一张切换而变化；横版、竖版、方图都在同一区域内完整显示。
2. 初始状态为“适应区域”，图片完整显示且不裁切。
3. 支持鼠标滚轮以光标位置为中心缩放，缩放范围 100%~600%；放大后可按住鼠标拖动查看局部。
4. 双击图片复位到适应区域；不显示缩放比例，也不提供加减缩放和复位按钮。
5. 切换照片、关闭后重新打开时，缩放比例和位移都复位。
6. 上一张/下一张固定在图片区左右两侧的垂直居中位置，不随信息区内容变化；指针进入图片区时显示，移出后隐藏，首尾不可用时隐藏对应按钮。
7. 触屏设备支持双指缩放与单指拖动，规则与鼠标一致；切换按钮在触屏下保持可见，未缩放时横向滑动仍可用于切换照片。
8. 使用方向键切换照片时，焦点保持在弹窗内，不重新聚焦关闭按钮，也不出现关闭按钮的焦点高亮。
9. 缩放和拖动只改变查看方式，不改变照片文件，不提供下载或另存入口。

**信息区：**

1. 标题；缺失时显示“未命名照片”。
2. 描述；缺失时显示“暂无描述”。
3. 拍摄时间、相机、镜头、焦距、光圈、快门、ISO；缺失字段隐藏。
4. 可选结构化位置；完全未填写时显示“未记录”。
5. 不展示原始 EXIF 块、原始 GPS 数据、编辑身份或审核信息。

**关闭与恢复：**支持关闭按钮、`Esc` 和点击弹窗外区域；关闭后保留查询与页码，焦点返回原照片，弹窗打开时焦点不离开。

## 6. 编辑工作区功能需求

### 6.1 工作区与本人内容列表 `FR-EDIT-LIST`

**导航：**我的文章专栏、我的文章、我的摄影专栏、我的相册、我的照片、我的审核记录、本人回收站。

**列表能力：**

- 只显示本人创建或上传的内容。
- 按名称或标题搜索，按公开状态、审核状态和标签筛选，每页 12 项。
- 同时显示公开状态与审核状态，例如“已发布 + 待审核”。
- 已公开但因上级下线而隐藏时显示具体原因。
- 提供新增、编辑、预览、提交审核、撤回、下线、移入回收站等当前允许操作。
- 不提供审批通过、直接发布、首页配置、他人内容或永久删除入口。

### 6.2 编辑专栏、相册与文章 `FR-EDIT-CONTENT`

**文章专栏：**名称、简介、封面、多个主题标签。

**文章：**标题、所属本人文章专栏、摘要、多个主题标签、发布时间、正文内容块。

**摄影专栏：**名称、简介、封面、摄影题材、多个主题标签。

**相册：**所属本人摄影专栏、标题、简介、封面、多个主题标签、创建时间、相册最新更新时间、可选主要拍摄位置。

**提交审核前的必填规则：**

| 内容 | 提交前必须具备 | 明确选填 |
|---|---|---|
| 文章专栏 | 名称、简介、封面 | 主题标签 |
| 文章 | 标题、所属本人文章专栏、摘要、不晚于提交当天的发布时间、至少一个有效正文内容块 | 主题标签及其他正文增强内容 |
| 摄影专栏 | 名称、简介、封面、摄影题材 | 主题标签 |
| 相册 | 所属本人摄影专栏、标题、简介、封面 | 主题标签、主要拍摄位置 |
| 照片 | 所属本人相册、有效原图、可用公开衍生图、不晚于提交当天的拍摄时间 | 标题、描述、主题标签、位置、其他展示元数据 |

管理员直接发布时使用相同必填规则。草稿可以暂缺上述项目，但提交审核或直接发布时必须完整。

**共同规则：**

1. 草稿允许暂不完整；提交审核前校验必填项。
2. 相册创建时间和最新更新时间为只读信息，不由编辑手工伪造。
3. 编辑可在本人容器下创建下级，不能选择他人容器。
4. 预览区分“当前公开版”和“待提交工作版”。
5. 新内容提交后进入待审核；已有公开内容的修改提交后，旧版继续公开。
6. 待审核版本可撤回；撤回后回到可编辑状态，公开旧版不变。
7. 驳回版本保留提交内容和驳回理由，编辑可继续修改并重新提交。
8. 离开有未保存修改的页面前需要确认。
9. 文章专栏和摄影专栏的字段修改同样形成工作版本；提交后公开端保持原版本，管理员审批通过后才更新。

### 6.3 编辑照片上传 `FR-EDIT-PHOTO`

1. 编辑只能向本人相册上传照片。
2. 单次最多选择 20 张，按 `RULE-UPLOAD` 校验和分片上传。
3. 上传后可查看每张照片的处理中、待补充信息、可提交和失败状态。
4. 可从可用原始信息中读取拍摄时间、相机、镜头、焦距、光圈、快门和 ISO；首版不读取、不存储原始 GPS，位置只由上传者手动填写。
5. 原始信息只用于生成可展示字段；编辑确认哪些结构化信息公开展示。
6. 拍摄时间为发布必填项；读取失败时编辑可手动补充。
7. 标题、描述、标签、位置和其他元数据均可选填。
8. 上传成功不等于公开；照片及其衍生图准备完成后仍需提交管理员审批。
9. 部分照片失败不影响已成功照片，失败项可重试，不能重复创建成功照片。

### 6.4 编辑下线、软删除与恢复 `FR-EDIT-LIFECYCLE`

| 操作 | 编辑权限与结果 |
|---|---|
| 下线本人已公开内容 | 可立即执行，公开端隐藏；不需要通过“上线审批” |
| 重新上线 | 提交管理员审批；通过后才恢复公开 |
| 移入本人内容回收站 | 二次确认后执行，公开端立即隐藏，原图和衍生图暂时保留 |
| 恢复本人回收站内容 | 恢复为已下线状态，不直接公开；重新上线仍需审批 |
| 永久删除 | 无权限，只能由管理员在回收站执行 |

**限制：**

- 含下级的专栏或相册不能整体移入回收站，需先处理其下级，防止批量隐藏和误删。
- 下线或移入回收站时，关联待审核版本自动撤回并保留为工作版本；恢复后可重新提交。
- 编辑不能通过修改地址、请求参数或他人内容链接执行越权操作。

### 6.5 审核结果与记录 `FR-EDIT-REVIEW`

- 编辑可查看本人内容的提交时间、当前审核状态、审核时间和驳回理由。
- 驳回理由必须完整展示，并允许从记录进入对应工作版本。
- 审核通过后，可查看当前公开版本；若因上级不可见而未公开，显示原因。
- 首版审核反馈在后台提供，不要求邮件或第三方消息通知。

## 7. 管理员后台功能需求

### 7.1 全站内容管理 `FR-ADMIN-CONTENT`

1. 管理员可查看所有者的专栏、文章、相册和照片，并按所有者、公开状态、审核状态、标签和时间筛选。
2. 管理员可新增、编辑、预览、直接发布、下线、移入回收站和恢复任何内容。
3. 管理员直接公开的新增或修改不经过编辑审批，但必须通过相同的内容和文件校验。
4. 管理员代编辑修改时不改变内容所有者，并记录实际操作管理员。
5. 管理员不能通过本站后台新增其他管理员。
6. 管理员可查看内容当前公开版、工作版及审核记录，避免误将工作版当作公开版。

### 7.2 审批中心 `FR-ADMIN-REVIEW`

**审批列表：**

- 按提交时间排列待审版本，支持按内容类型、提交编辑和日期筛选。
- 显示提交人、所属内容、首次发布或修改、提交时间和当前公开状态。
- 对待审修改提供当前公开版与提交版的差异预览；图片替换需对比衍生预览图。
- 审批详情必须提供完整预览：正文按公开端规则渲染，图片、代码、公式和图示实际显示；照片显示大图、描述、可展示元数据和位置。
- 预览加载失败时不能执行通过，只能驳回或稍后处理，避免管理员在未查看内容的情况下放行。

**审批通过：**

1. 再次校验提交版本、内容归属、上级公开状态和衍生图可用性。
2. 新内容通过后形成首个公开版本；修改通过后以提交版替换旧公开版。
3. 审批期间编辑已撤回版本时，该审核不可再通过，并提示版本已变化。
4. 上级不可见时不能直接使下级公开。
5. 通过后记录审核人、审核时间和对应版本，并更新相应公开时间字段。

**审批驳回：**

1. 驳回理由必填，指出需要修改的具体问题。
2. 新内容驳回后仍不公开；已公开内容的旧版继续展示。
3. 工作版本和理由保留给提交编辑查看与修改。
4. 驳回不删除已上传原图，允许编辑基于原内容重新提交。

**并发与失败：**

- 同一份工作版本只能产生一次有效审批结果，重复点击不得重复发布。
- 审批保存失败时不改变公开版本，并保留管理员可重试的操作。
- 审批结果生效后不能再直接撤销决定；需要纠正时由管理员下线或发布修正版本。

### 7.3 首页推荐与目标数量 `FR-ADMIN-HOME`

**配置能力：**

- 分别设置推荐文章目标数量 `N₁` 和推荐相册目标数量 `N₂`。
- 从当前公开可见内容中选择推荐项并调整顺序。
- 预览手动推荐和自动补位后的实际首页结果。
- 保存、清空或恢复全自动推荐。

**目标数量规则：**

1. `N` 为非负整数；`0` 表示隐藏对应推荐区。
2. 默认值和上限待排版设计确认，见 `[TBD-02]`。
3. 手动推荐数量不能超过当前目标数量。
4. 调低目标数量导致已选项超限时，保存前提示将移除超出部分；确认后保留管理员顺序中的前 `N` 项。
5. 调高目标数量后，保留原手动顺序，不足部分自动补位。
6. 推荐配置保存失败时，公开首页继续使用上一次完整配置，不展示半完成状态。

### 7.4 回收站与永久删除 `FR-RECYCLE`

**进入回收站：**

- 编辑可移入本人内容，管理员可移入任何内容。
- 已公开内容进入回收站后立即从公开端和首页推荐移除。
- 原图、衍生图、工作版本和审核记录暂时保留，允许恢复。
- 非空专栏或相册必须先处理下级，不能整体带下级移入回收站。

**恢复：**

- 编辑只能恢复本人内容，管理员可恢复全部。
- 恢复前校验上级仍存在且不在回收站；不满足时阻止恢复并提示先恢复或更换上级。
- 恢复后统一为“已下线”，不直接返回公开状态。
- 编辑恢复后需重新提交审批；管理员可校验后重新发布。

**永久删除：**

1. 仅管理员可在回收站执行。
2. 永久删除前进行二次确认，明确内容名称、所有者和将清除的文件。
3. 确认后删除内容及其版本记录、原图、公开衍生图和对应本地文件，不再允许恢复；仅保留不含内容文件的最小操作审计记录。
4. 删除照片后按照相册时间回算规则重新计算所属相册最新更新时间。
5. 删除失败时保留回收站记录并提示失败项，不能表现为已成功。
6. 永久删除会清除原图、公开衍生图、云端副本、处理临时文件及缓存；数据库备份中的历史副本无法按单条记录定点删除，随备份轮转（保留 30 天）自动失效，不在即时清除范围内。全部可清除项成功后才提示删除完成，任一失败保留记录并允许重试。

### 7.5 系统管理 `FR-ADMIN-SYSTEM`

管理员拥有整个程序的管理能力，首版至少包括：

- 账号管理：创建普通账号、授予与撤销编辑权限、重置密码、禁用与启用。
- 全站内容与审批管理。
- 首页推荐和目标数量配置。
- 回收站和永久删除。
- 标签词库管理：查看标签及使用数量、重命名、合并、停用；审批内容时移除不当标签。
- 只读系统信息：版本、构建状态、存储用量和任务状态，仅查看不可修改。
- 必要的操作记录查看，包括审批、权限变化、直接发布、下线和永久删除。

上传限制、衍生图压缩策略、水印参数和会话安全策略属于部署配置，通过配置文件或环境变量维护，首版不在后台提供可修改界面。

标签规则：编辑在编辑内容时可直接输入新标签，新标签随内容一并提交审批，编辑没有独立标签管理入口；管理员可在审批时移除提交内容中的部分标签，也可重命名、合并或停用标签。标签词库分为文章与摄影两组，编辑创建的新标签默认归入当前内容所属作用域，管理员不能把标签挂载到另一作用域；这些变更立即影响已公开内容和筛选结果，不触发重新审批。

### 7.6 后台设备分级 `RULE-ADMIN-DEVICE`

**高风险操作，仅 PC 提供：**

| 操作 | 风险原因 |
|---|---|
| 永久删除并清除文件 | 唯一不可恢复的操作，原图和衍生图一并清除 |
| 创建账号 / 授予 / 撤销编辑权限 / 重置密码 / 禁用启用 | 作用于他人账号，撤权或禁用可能级联影响其登录与内容公开状态 |
| 管理员直接修改并公开他人内容 | 绕过审批流程，覆盖编辑的公开版本 |
| 审批通过并替换已公开版本（修改类） | 旧公开版被覆盖，无一键回滚，纠正需重新走发布流程 |
| 标签合并 / 重命名 / 停用 | 同时改变全部已公开内容的标签与筛选结果，影响范围跨所有者 |

首次发布（当前没有公开版本）的审批通过不属于替换操作，手机端可用；手机端只支持单条通过，首版不提供批量通过。

标签合并、重命名与停用属于高风险操作，仅 PC 提供。

**手机端可用的后台操作：**查看列表与审核记录、草稿编辑与保存、提交审核、撤回待审版本、单篇内容下线与恢复、移入回收站与恢复、首次发布审批通过（单条）、审批驳回、首页推荐排序与目标数量调整。

**设备规则：**

1. 手机端不显示高风险操作入口；即使通过地址或参数访问，这些操作也不生效。
2. 平板在桌面布局下视同 PC，可执行高风险操作；窄屏布局按手机规则处理。
3. 设备限制是额外防线，不替代权限校验；全部操作仍受二次确认、权限验证和操作记录约束。

### 7.7 后台交互细则 `FR-ADMIN-INTERACTION`

> 本节定义管理员后台的具体操作反馈与状态变化，供排版和交互设计使用。编辑工作区沿用同一套通用约定。

#### 7.7.1 通用交互约定

**布局与导航**

1. 后台采用固定左侧导航，分组为“内容”“运营”“管理”，当前项高亮。
2. 审批中心导航项显示待审数量徽章；回收站显示条目数；数量为 0 时不显示徽章。
3. 在同一次登录会话内，各列表的筛选条件、排序和页码在切换导航后保留；点击“重置条件”才清空。
4. 顶部栏固定显示面包屑、当前角色徽章、主题切换和账号菜单；账号菜单提供退出登录。
5. 品牌区域回到后台首页，不直接跳转公开首页。

**加载与反馈**

1. 列表首次加载显示骨架占位，不使用整页白屏；超过约 1 秒显示“加载中”说明。
2. 行内操作使用该行的局部加载状态，处理期间不清空整张表、不丢失滚动位置。
3. 操作成功后在页面顶部显示短暂提示，包含操作对象名称，例如“「雨后城市漫步」已下线”，数秒后自动消失，可手动关闭。
4. 操作失败的提示常驻，直到关闭或重试；必须说明失败对象和原因，不能只显示“操作失败”。
5. 成功提示不阻塞下一步操作；失败提示不自动消失。
6. 提交类按钮在处理期间禁用，防止重复提交；重复提交不得产生重复结果。
7. 耗时操作（永久删除、批量下线）显示进度和当前处理对象；离开页面不代表任务取消，完成后仍给出结果提示。

**表单与保存**

1. 必填项有明确标记；提交时校验失败则定位并聚焦第一个错误字段，同时在字段旁说明原因。
2. 保存草稿不校验必填；提交审核或直接发布才执行完整校验。
3. 有未保存修改时显示“未保存”状态；保存成功后显示最近保存时间。
4. 保存失败保留全部输入，不清空字段、不刷新页面。
5. 编辑页支持 `Ctrl/Cmd + S` 保存草稿；`Esc` 关闭当前弹窗；`Tab` 顺序符合视觉阅读顺序。
6. 离开存在未保存修改的页面前必须确认；浏览器刷新或关闭同样提示。

**列表与批量**

1. 筛选条件集中于列表上方；应用多个条件后显示“已应用 N 个条件”，每个条件可单独移除。
2. 可勾选表格首列复选框；支持全选当前页。跨页选择时显示“已选 N 项，包含其他页”。
3. 批量操作只对允许操作的对象生效；不合法对象自动跳过，并在结果中列出跳过原因。
4. 批量操作执行前显示确认弹窗，列明数量、对象类型和影响。
5. 可排序表头显示当前排序方向；切换排序后回到第 1 页。
6. 每页 12 项；翻页保留筛选与勾选状态。

**空态与权限态**

1. 区分三种空态：原始无数据、条件无匹配、加载失败；三者文案和操作入口不同。
2. 条件无匹配时提供“重置条件”，原始无数据时不显示重置按钮。
3. 会话失效时拦截当前操作并提示重新登录；重新登录后回到原页面，尽量保留已填写内容。
4. 权限变化导致操作被拒绝时，提示“你的权限已变化，页面将刷新”，刷新后按最新权限展示。

**确认弹窗**

1. 结构固定为：标题（动作 + 对象名）、影响说明、不可逆提示（如适用）、取消和确认按钮。
2. 危险操作的确认按钮使用危险色，默认焦点落在“取消”。
3. 点击遮罩不关闭危险确认弹窗，避免误操作；普通弹窗可点击遮罩关闭。
4. 确认执行后，弹窗切换为进行中状态，不能重复点击确认。

#### 7.7.2 审批中心交互 `FR-ADMIN-REVIEW`

**列表与详情：**

1. 左侧队列默认按“最早提交在前”排列，可切换为“最近提交在前”；每项显示内容类型、标题、提交人、等待时长和是否为首次发布。
2. 点击队列项在右侧加载详情；选中项在队列中保持高亮。
3. 修改类内容默认打开“差异”视图，新内容默认打开“提交版”视图。
4. 详情标签页为“提交版 / 当前公开版 / 差异”；当前无公开版时隐藏“当前公开版”和“差异”。
5. 差异视图按字段高亮新增、删除和修改；图片替换显示为并排或滑块对比。
6. 长文差异可开启“滚动同步”，两栏滚动位置保持一致。
7. 正文预览使用与公开端一致的内容块展示规则，不因后台而改变公式、代码或图示的呈现。

**内容预览：**

1. 每条待审项提供“预览”入口，以独立弹层或右侧预览区展示完整内容，不跳转公开端。
2. 修改类预览顶部提供“提交版 / 当前公开版”切换，首次打开默认提交版。
3. 文章预览展示标题、标签、正文、图片、代码、公式和图示；相册预览展示相册信息和照片网格，可点开单张大图；照片预览展示大图、描述、可展示元数据和位置。内容预览中的标签可逐个移除，移除只作用于本次提交版本，不删除标签词库中的标签，并写入审计。
4. 预览图片只使用公开衍生图，不加载原图；预览中不显示未获准公开的元数据。
5. 未打开过预览的条目显示“未预览”标记；打开后标记变为“已预览”。
6. 预览除标签移除外为只读，不提供其他编辑入口；预览中的外部链接不直接跳转，需二次确认。
7. 预览加载失败时禁用“通过”并说明原因，管理员只能驳回或稍后处理。

**审批通过：**

1. 点击“通过”先显示确认摘要：内容名称、首次发布或修改、是否将替换公开版、将更新的公开时间字段；若审批中移除了标签，摘要列出被移除的标签。
2. 确认后执行；成功后队列自动选中下一条，并提示结果。
3. 若因上级不可见而无法公开，提示“已通过，但上级未公开，暂不在前台展示”，并给出上级入口。
4. 版本已被编辑撤回或内容已被移入回收站时，操作被拒绝，提示“该版本已变化，无法审批”，并刷新队列。
5. 首版不提供批量通过，避免误将未检查内容公开。

**审批驳回：**

1. 点击“驳回”后在操作区展开理由输入框，理由必填；为空时不能提交。
2. 提供若干常用驳回原因供快速填入，管理员可在填入后继续编辑。
3. 驳回确认弹窗说明：新内容将不公开；已公开内容继续保留旧版。
4. 驳回成功后队列前移，提示包含“已通知提交编辑”的说明。

**快捷键：**`Tab` 焦点顺序为标签页 → 内容区 → 操作按钮；在队列中可用上下方向键切换条目，`Enter` 打开选中条目。

#### 7.7.3 全站内容管理交互 `FR-ADMIN-CONTENT`

1. 顶部类型标签页为“全部 / 文章专栏 / 文章 / 摄影专栏 / 相册 / 照片”；切换时清空不适用于该类型的筛选条件，并回到第 1 页。
2. 筛选面板可折叠，包含所有者、公开状态、审核状态、标签和日期；条件以标签形式展示，可逐个移除。
3. 表格固定列为：名称与封面、所有者、公开状态、审核状态、更新时间、操作。
4. 点击行进入详情或编辑；点击行内操作按钮不触发行跳转。
5. 行内最多显示 3 个操作，其余收进“更多”菜单；菜单按“查看 / 编辑 → 下线或恢复 → 移入回收站”顺序排列。
6. 管理员直接编辑他人内容时，编辑页顶部常驻提示“管理员直接编辑：保存并公开将立即覆盖公开版本”，并提供“保存为草稿”和“保存并公开”两个独立按钮。
7. 下线确认弹窗列出将影响的已发布下级数量和首页推荐数量；确认后执行并给出结果。
8. 对非空专栏或相册执行移入回收站会被阻止，提示“请先处理 N 个下级内容”，并提供查看下级入口。
9. 列表显示“已发布但因上级不可见而隐藏”的内容时，状态列说明具体原因，并提供上级入口。
10. 手机端操作折叠进“更多”，高风险操作不显示。

#### 7.7.4 首页推荐配置交互 `FR-ADMIN-HOME`

1. 页面分为“推荐文章”和“推荐相册”两个独立配置区，各自可单独保存；两个区都有未保存修改时，显示“保存全部”。
2. 目标数量使用数字输入加步进按钮；输入非整数、负数或超出上限时即时提示，且不能保存。
3. 可选内容池只包含当前公开可见内容，支持搜索和按标签筛选；每项显示缩略图、标题、更新时间和“添加”按钮。
4. 已添加项在可选池中显示“已添加”并禁用，避免重复推荐。
5. 已选区按管理员顺序横向排列，支持拖拽排序；拖拽时显示插入位置；键盘可用上移、下移按钮完成同样操作。
6. 手动推荐数量达到目标数量时，“添加”按钮禁用并提示“已达目标数量，如需添加请先移除或调高数量”。
7. 调低目标数量导致手动项超限时，保存前弹窗逐项列出将被移除的内容，确认后保留顺序中前 N 项。
8. 实时预览区模拟首页推荐区布局，自动补位项带“自动补位”标记，与手动项可区分但不影响访客端展示。
9. 保存成功后提示并清除未保存标记；保存失败保留本次设置并提供重试，公开首页继续使用上一次完整配置。
10. 清空手动推荐需确认，确认后该区变为全自动推荐，目标数量保持不变。
11. 有未保存修改时离开页面需要确认。

#### 7.7.5 账号权限交互 `FR-ADMIN-USERS`

1. 顶部支持按用户名或邮箱搜索；列表显示用户名、邮箱、当前角色徽章、账号状态、最近活动和操作；最近活动取最近登录时间或最近一次后台操作时间，无记录显示“—”。
2. 提供“创建账号”入口，填写用户名、邮箱、初始密码和是否同时授予编辑权限；用户名和邮箱均需唯一，不合规时即时提示且不能提交。
3. 管理员账号行标记“由服务器管理”，该行不提供创建、授予、撤销、重置密码或禁用入口，仅可查看。
4. 授予编辑权限前弹窗说明权限范围：只能管理本人创建的内容，新增和修改均需管理员审批；确认后该行角色立即更新为“编辑”。
5. 撤销编辑权限前弹窗列出影响：无法继续编辑或提交、待审核内容由管理员接管、已公开内容保留并转归管理员；需勾选“我已知晓上述影响”后才能确认，确认按钮为危险色。
6. 重置密码打开弹窗，由管理员输入新密码并二次确认；成功后该账号已登录会话在下一次管理操作时失效，需用新密码重新登录。
7. 禁用账号需二次确认；禁用后该账号不能登录，已登录会话在下一次管理操作时被拒绝，列表状态显示“已禁用”。禁用不改变角色，也不影响其已公开内容归属；可重新启用。
8. 操作成功后在行内更新状态并提示结果；操作失败保留原状态，并说明失败原因，不能出现界面已改但实际未生效的状态。
9. 创建账号、授予、撤销、重置密码和禁用 / 启用均属于高风险操作，仅 PC 可见；手机端该页只读，不显示上述入口。

#### 7.7.6 回收站交互 `FR-RECYCLE`

1. 顶部类型标签页筛选内容类型；列表显示名称、类型、所有者、删除人、删除时间和操作。
2. 删除人为编辑或管理员时分别标注，便于判断来源。
3. 恢复前确认；恢复成功提示“已恢复为已下线，重新上线仍需发布或审批”。
4. 上级不可用或已在回收站时阻止恢复，提示需先恢复上级，并提供上级入口。
5. 支持批量恢复；批量结果中列出成功与跳过项。
6. 永久删除按钮仅管理员可见，且仅 PC 显示；点击后弹窗展示对象名称、所有者、将清除的原图数量与衍生图数量，以及“不可恢复”提示。
7. 永久删除需勾选“我已知晓此操作不可恢复”后才能确认；执行时显示进度和当前处理对象。
8. 永久删除成功后从列表移除并给出结果；失败时保留该条记录，列出失败文件并提供重试。
9. 首版永久删除仅支持单条执行，不提供批量永久删除。

#### 7.7.7 系统管理与日志交互 `FR-ADMIN-SYSTEM`

**系统管理：**

1. 页面按“标签词库 / 只读系统信息 / 操作审计入口”分组，每组独立卡片；标签词库内再按文章、摄影两个作用域分组，默认停留在文章组。
2. 只有标签词库可修改；修改标签后显示未保存状态，保存成功提示，保存失败保留修改值并说明原因。
3. 只读系统信息展示版本、构建状态、存储用量和任务状态，以及上传限制、衍生图策略、水印参数和会话安全策略的当前部署值；不提供修改和保存按钮。
4. 标签词库展示每个标签的使用数量；合并或停用标签时，先显示将受影响的内容数量，要求二次确认。
5. 合并标签需先选择同作用域的目标标签，再确认合并，跨作用域不可选；停用标签后该标签不再出现在本作用域筛选器中，已使用该标签的内容保留原记录。
6. 标签合并、重命名与停用属于高风险操作，仅 PC 可见；变更立即影响已公开内容与筛选结果，不触发重新审批。

**日志与审计：**

1. 日志只读，不提供编辑或删除入口。
2. 支持按操作类型、操作人、对象类型和时间范围筛选，每页 12 项。
3. 列表显示时间、操作人、操作类型、对象和结果；操作类型使用徽章区分普通操作、审批、权限变化、直接发布、下线和永久删除。
4. 点击行展开详情，显示操作前后状态摘要、影响范围和失败原因（如有）。
5. 失败操作同样记录，并与成功记录区分显示。
6. 日志不展示原图内容或完整元数据，只记录对象标识和操作结果。

## 8. 共用业务规则

### 8.1 公开列表 `RULE-LIST`

| 行为 | 统一规则 |
|---|---|
| 搜索 | 点击搜索或按 Enter；去除首尾空格；中文按包含关系匹配，英文忽略大小写 |
| 多维筛选 | 不同维度之间取交集；同一标签维度按 `RULE-TAG` 的全部包含规则 |
| 日期 | 使用 `RULE-DATE`；改变日期后回到第 1 页 |
| 排序 | 立即生效；相同排序值按标题稳定排列；变更后回到第 1 页 |
| 分页 | 公开列表和后台管理列表每页 12 项，提供上一页、页码、下一页和结果总数 |
| 翻页 | 不改变查询条件；翻页后回到当前列表顶部 |
| 重置 | 清空关键词、标签、其他筛选和日期，恢复默认排序及第 1 页 |
| 返回恢复 | 从详情返回或关闭照片弹窗后保留查询、日期、排序和页码 |
| 无匹配结果 | 显示“没有找到匹配内容”和“重置条件”，隐藏分页 |
| 原始空内容 | 显示“暂无文章 / 相册 / 照片”，隐藏无效查询工具，保留返回入口 |
| 加载失败 | 显示失败说明和重试，保留查询条件与页码 |

### 8.2 多标签组合筛选 `RULE-TAG`

**作用域隔离：**

1. 主题标签分为“文章”和“摄影”两个独立词库，每个标签带有唯一作用域，内容只能挂载本作用域的标签。
2. 文章侧列表只展示文章标签，摄影侧列表只展示摄影标签；技术类标签不得出现在摄影筛选中，摄影类标签不得出现在文章筛选中。
3. 两个作用域允许存在同名标签，以标签 ID 区分，不互相合并、不同步改名、不同步停用。
4. 摄影的“题材”（街拍 / 自然风光 / 城市风光）是独立枚举字段，不属于标签词库，也不参与标签组合筛选。
5. 标签应用、移除、重命名、合并与停用只在所属作用域内生效，跨作用域合并禁止。

**筛选规则：**

1. 文章专栏、文章、摄影专栏、相册和照片均可拥有多个主题标签。
2. 公开端标签筛选支持多选；未选择标签表示不限制。
3. 同一列表中选择多个标签时，内容必须**同时含有全部已选标签**才展示，即逻辑 `AND`。
4. 内容可以拥有未参与筛选的其他标签，不要求内容标签集合与用户选择完全相同。
5. 不同维度之间继续取交集，例如“题材 = 街拍”且“同时含有标签 A、B”。
6. 新增或移除标签后回到第 1 页。

**示例（摄影作用域）：**

```text
内容甲标签：街拍、夜景、雨天
内容乙标签：街拍、城市
用户选择：街拍、夜景

结果：只展示内容甲。
内容乙缺少“夜景”，即使含有“街拍”也不展示。
```

**标签创建与维护：**

1. 编辑在编辑内容时可直接输入新标签，没有独立标签管理入口；新标签随内容一并提交审批。
2. 管理员审批时可将提交内容中的部分标签移除；需要删除整篇内容时走驳回、下线或回收站流程，不以删标签代替。
3. 管理员可重命名、合并或停用标签；合并需先选择目标标签。
4. 重命名、合并与停用立即作用于已公开内容和公开筛选结果，不触发内容重新审批。
5. 停用标签不再出现在筛选器中；已使用该标签的内容保留标签记录，但无法再通过该标签筛出。

### 8.3 日期筛选 `RULE-DATE`

**边界：**最早可选日期按列表分别确定：文章专栏和摄影专栏取当前公开专栏中最早的创建日期，文章取最早的发布日期，相册取最早的相册最新更新时间，照片取当前公开照片中最早的拍摄日期。最晚均为访问当天，起止日期均包含当天。对应列表没有公开内容时不提供日期筛选。

| 列表 | 日期字段 |
|---|---|
| 文章专栏 | 专栏创建日期 |
| 文章 | 文章发布日期 |
| 摄影专栏 | 专栏创建日期 |
| 相册 | 相册最新更新时间的日期 |
| 照片 | 照片拍摄日期 |

**规则：**

1. 开始和结束日期均可单独填写。
2. 只填开始日期：筛选该日期至今天。
3. 只填结束日期：筛选最早边界至该日期。
4. 开始日期晚于结束日期时不执行查询，提示并保留输入。
5. 不选择晚于当天的日期。
6. 清除日期不影响其他条件，但回到第 1 页。

### 8.4 可选位置 `RULE-LOCATION`

位置不再作为发布必填项。国家、省/州、城市、区/县、镇/村、街道和具体地点均可选填。

1. 可只填写部分层级，发布时不因位置缺失或层级不完整而阻断。
2. 按“国家 → 省/州 → 城市 → 区/县 → 镇/村 → 街道 → 具体地点”顺序展示已填内容。
3. 跳过未填层级，不显示空白占位或多余分隔符。
4. 所有字段均为空时，照片详情显示“未记录”。
5. 位置只由上传者或管理员手动填写；系统不读取、不存储原始 GPS，也不基于 GPS 生成位置建议。
6. 原始 GPS 和完整 EXIF 不进入公开字段或公开图片；位置只来自上传者或管理员手动填写的结构化字段。

### 8.5 上传限制与分片过程 `RULE-UPLOAD`

| 用途 | 支持格式 | 单张大小 | 单次数量 |
|---|---|---|---|
| 文章图片 | JPG、PNG、WebP、HEIC / HEIF | 小于 5 MB | 每批最多 20 张 |
| 摄影照片 | JPG、PNG、HEIC / HEIF | 小于 50 MB | 每批最多 20 张 |

**校验规则：**

1. 按实际文件格式校验，不只信任文件扩展名。
2. 等于或超过对应大小上限的文件不可上传，并明确提示限制。
3. 一次选择超过 20 张时阻止该批次提交，提示减少到 20 张以内，不静默丢弃文件。
4. 不支持格式或超限文件单独标记失败，其余合规文件可继续。

**分片上传：**

1. 合规文件采用分片上传，逐张显示总进度和当前状态。
2. 分片失败时重试失败部分，已成功分片不重复上传。
3. 单张失败不影响同批其他照片；用户可取消单张或重试失败项。
4. 所有分片完成后才形成有效原图，再生成公开衍生图。
5. 衍生图生成失败时保留有效原图并允许重新处理，不要求重新上传全部文件。
6. 上传或处理完成不等于公开；编辑内容仍需审批。
7. 重复提交不得生成重复内容或重复覆盖已成功文件。

### 8.6 原图、衍生图与元数据安全 `RULE-MEDIA`

1. 上传原图私有保留，不对访客提供下载按钮或公开原图地址。
2. 编辑只能访问本人原图，管理员可访问全部原图；访客和无权限登录者不能访问。
3. 公开页面、文章正文、相册瀑布流和照片弹窗只使用压缩衍生图。
4. 衍生图必须剥离 EXIF、GPS 及其他嵌入元数据，不携带原始拍摄参数块。
5. 无论访客通过网页保存、直接图片请求或其他公开方式获取，都只能得到压缩且无嵌入元数据的衍生图。
6. 拍摄参数从上传时读取的信息中提取为允许的展示字段，不由公开图片文件携带。
7. 公开端只展示标题、描述、拍摄时间、相机、镜头、焦距、光圈、快门、ISO 和确认后的位置等明确字段，不输出完整原始信息。
8. HEIC / HEIF 等格式必须生成适合公开展示的衍生图，不能因访客浏览器不支持原格式而无法浏览。
9. 原图和衍生图在软删除时保留，在管理员永久删除时按 `FR-RECYCLE` 清除。
10. 衍生图格式、压缩质量和尺寸策略见技术选型 8.7“图片交付与防盗”：瀑布流长边 480 / 960，相册网格 960，详情 1440 / 2048，大屏最大 2560，统一 WebP 并保持原始比例。

### 8.7 操作失败与不可逆行为 `RULE-SAFE`

| 场景 | 规则 |
|---|---|
| 提交审核失败 | 保留工作版本，可重试，不公开 |
| 审批失败 | 保留原公开版本和待审版本，可重试，不产生部分更新 |
| 权限被撤销 | 新操作立即拒绝，公开旧版按撤权规则处理 |
| 下线 | 明确影响范围；下级和首页推荐同步隐藏 |
| 移入回收站 | 二次确认，文件保留，可恢复为已下线 |
| 永久删除 | 仅管理员，二次确认，清除文件后不可恢复 |
| 上传部分失败 | 成功项保留，失败项单独重试，不重复创建 |
| 未保存离开 | 提示继续编辑或放弃修改 |

## 10. 多端、主题与内容风格（原 9. 章节顺延）

### 10.1 多端浏览 `RULE-RESPONSIVE`

| 页面或组件 | PC | 平板 | 手机 |
|---|---|---|---|
| 全局导航 | 完整展示 | 保持主要入口可见 | 紧凑排列，不遮挡主题切换 |
| 查询工具栏 | 搜索与筛选分组排列 | 可换行 | 按操作顺序纵向排列 |
| 文章与专栏卡片 | 多列 | 自适应减少列数 | 单列或适合阅读的双列 |
| 文章详情 | 正文与目录并列 | 并列或顶部目录 | 顶部可滚动目录，正文单列 |
| 照片瀑布流 | 多列 | 自适应减少列数 | 自适应列数，保证照片可辨识 |
| 照片弹窗 | 大图与信息区并列 | 并列或上下布局 | 上下布局，弹窗内滚动 |
| 编辑与管理员后台 | 完整管理布局 | 桌面布局视同 PC | 除高风险外全部可用，高风险仅 PC |

**共同要求：**

- 不产生非预期页面级横向滚动；代码、公式和复杂图示只在自身内容块内滚动。
- 屏幕变化或设备旋转不重置当前查询、页码和编辑内容。
- 不依赖 hover 完成关键操作，触屏可使用所有公开端控件。
- 所有关键操作支持键盘和可见焦点；照片弹窗正确管理焦点。

### 10.2 浅色与深色主题 `RULE-THEME`

1. 全局导航提供浅色 / 深色切换，当前模式明确可见。
2. 未保存偏好时跟随设备系统主题。
3. 用户主动切换后以当前浏览器保存值为准，不再随系统自动变化。
4. 刷新、同一浏览器中的其他本站页面及下次访问均保持选择。
5. 主题偏好不需要登录，不要求跨设备同步。
6. 清除网站数据后恢复跟随系统的首次访问规则。
7. 本地保存不可用时，本次访问仍保持选择，不阻断浏览。
8. 深色模式不是简单反色，文字、代码、公式、Mermaid、边框和弹窗均需可辨识。
9. 照片不反色、不通过主题改变照片本身色彩。

### 10.3 视觉与内容风格

**总体方向：编辑式叙事 × 技术清晰度 × 中性画廊。**

- 使用有纸张与档案感的编辑式排版，同时保持技术文档的秩序。
- 标题可使用衬线风格，正文使用清晰非衬线风格，代码使用等宽字体。
- 保留充分留白，减少无意义卡片堆叠、重阴影和装饰性渐变。
- 浅色模式偏暖纸张与深墨色，深色模式偏墨绿或炭灰，避免纯黑纯白强刺激。
- 公开端不通过作者页或编辑标签区分内容生产者，保持统一网站品牌。

**旅记风格参考：**

- 强调时间、地点、路线与叙事，可使用较大的章节图片和图注。
- 更温暖、更具杂志感，但保留目录和长文定位。
- 以上仅用于设计，不生成专栏分类或筛选项。

**技术文档风格参考：**

- 强调结构、扫描效率、代码、公式和 Mermaid 的可读性。
- 装饰克制，可使用较冷辅助色与细线分隔。
- 以上仅用于设计，不生成专栏分类或筛选项。

**摄影风格：**

- 街拍突出时间、可选位置和现场描述。
- 自然风光利用大图和留白呈现空间感。
- 城市风光强调几何秩序和不同画幅的混排。
- 三类题材共用页面结构，不制作互相割裂的视觉皮肤。

**后台风格：**

- 公开版、工作版、待审版、驳回版和回收站状态清晰可辨。
- 编辑与管理员看到不同功能和数据范围，但组件语言保持一致。
- 审批差异、权限变化、失败和永久删除警告优先于装饰。

**页脚与阅读余量：**

- 全站使用内容型页脚，承载站点简介、栏目入口、主题切换和版权信息；PC 高度约 240–360px，手机按内容自然撑开。
- 页脚高度不作为目录定位的唯一手段；文章详情按 5.4 单独保留阅读余量，两者叠加保证末尾标题也能定位到视口顶部。
- 页脚与正文之间有明确分隔，深色模式不使用整块纯黑，避免像“内容没加载完”。

### 10.4 入场动效 `RULE-MOTION`

首版仅对首页推荐文章卡片和推荐相册卡片应用“进入视口淡入上移”，列表页、详情页暂不启用。

1. 卡片初始位移 12–16px、透明度 0；进入视口后 380–450ms 恢复到原位，缓动为 `cubic-bezier(.22,.61,.36,1)`。
2. 同组卡片按顺序递延 40–60ms，总递延不超过 240ms；首屏卡片直接显示或只做极轻淡入。
3. 只动画 `opacity` 与 `transform`，不动画高度、边距或滤镜，避免布局偏移。
4. 动效不能拦截卡片点击、键盘聚焦或链接跳转。
5. 初始隐藏样式由脚本添加；脚本失败或未执行时内容必须直接可见。
6. 浏览器前进、后退或锚点定位导致卡片被跳过时，观察器初始化检查和兜底计时器必须让卡片恢复可见。
7. 遵循 `prefers-reduced-motion: reduce`，关闭位移与淡入，内容直接显示。
8. 若后续推广到列表页，每次筛选、排序、分页重渲染后必须重新观察新卡片，避免卡片停留在透明状态。
